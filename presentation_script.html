Slide 2: Real-World Industry Challenges

Speaker 1: Suraj 1:15 - 2:30

Slide Visual: 4 Cards (Tool Fragmentation, Steep Coding Barrier, Missing Version Control, Manual Reporting).

"Before building IntelliHub AI, we identified four major real-world problems that data teams face today:

1. Tool Fragmentation: Engineers have to constantly switch between separate tools — Jupyter Notebooks for cleaning, PowerBI for graphs, and custom Python scripts for model training.
2. Steep Coding Barrier: Non-technical business analysts and domain experts cannot write complex Pandas or Scikit-Learn code, excluding them from data science workflows.
3. Missing Version Control: When raw datasets are edited or cleaned manually, there is zero tracking or versioning of changes.
4. Manual & Error-Prone Reporting: Extracting summaries and building executive reports takes hours of tedious manual effort.

To solve all these critical challenges under one roof, we created IntelliHub AI."

"Thank you, Suraj. Hello everyone, I am Nandish Patel.

Our platform provides Unified Data Intelligence through four key features:

Slide 4: The Core Data Pipeline

Speaker 2: Nandish 3:45 - 5:15

Slide Visual: 3-step Pipeline (Dataset Management → AI-Powered Cleaning → Exploratory Analysis).

"Let's look at how data moves through our core pipeline:

Step 1: Dataset Management: Users upload datasets in CSV, Excel, or JSON formats. Every time a dataset is modified or cleaned, our system automatically creates a new immutable version (v1, v2, v3) so historical raw data is never lost.

Step 2: AI-Powered Cleaning: Our cleaning engine uses statistical methods like Interquartile Range (IQR) and Z-Score for outlier detection, alongside Mean/Mode imputation for missing values.

Step 3: Exploratory Data Analysis (EDA): We generate over 12+ interactive Plotly visualization charts, correlation heatmaps, and statistical summaries instantly without writing a single line of code."
Live Demo Cue (Optional): Nandish can briefly show the Dataset Manager & Cleaner screen on the live website (intellihub-ai-portal.vercel.app).

Slide 5: AI, ML & Automation at the Core

Speaker 3: Himanshu 5:15 - 6:45

Slide Visual: Intelligence Layer (AutoML Leaderboard, Universal Web Scraper, AI Assistant & PDF Reports).

"Thank you Nandish. Good morning Jury, I am Himanshu Namsa.

I will explain the Intelligence Layer of IntelliHub AI:

1. AutoML Leaderboard: When a user selects a target variable, our AutoML engine trains multiple Scikit-Learn algorithms — including Random Forest, Support Vector Machines (SVM), K-Nearest Neighbors (KNN), and Decision Trees. It automatically benchmarks and ranks them based on R² Score, Accuracy, Precision, Recall, and F1-Score.

2. Universal Web Scraper: Users can input any website URL containing HTML tables. Our scraper automatically extracts tabular data, parses it using BeautifulSoup, and converts it into a clean dataset ready for analysis.

3. Automated Insights & PDF Reports: Our ReportLab engine synthesizes analytical summaries and generates downloadable, executive-ready PDF reports with charts and health scores."

Slide 6: Enterprise Architecture & Tech Stack

Speaker 3: Himanshu 6:45 - 8:00

Slide Visual: Enterprise Architecture Diagram (Frontend, Backend, AI/Processing, Security).

"Here is the technical architecture behind IntelliHub AI:

• Backend Framework: Built using Django 5 and Python 3.11/3.13, following the modular Model-View-Template (MVT) design pattern.
• Frontend UI: Crafted with a modern Dark Glassmorphism aesthetic using Bootstrap 5, HTML5, Vanilla CSS3, and FontAwesome 6 icons.
• AI & Processing Engine: Powered by Pandas and NumPy for high-performance data manipulation, and Scikit-Learn for machine learning models.
• Security & Deployment: Secure authentication with password hashing, CSRF protection, and session management, hosted live on Vercel cloud serverless platform."
