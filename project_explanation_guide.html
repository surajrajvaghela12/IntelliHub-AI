Chapter 1: What is IntelliHub AI? (Simple Explanation)

Imagine you have a messy Excel sheet with thousands of customer data rows, missing phone numbers, and random text. Normally, a data scientist has to write hundreds of lines of Python code in Jupyter Notebooks to clean the data, create charts in PowerBI, and train Machine Learning models in specialized software.

IntelliHub AI solves this problem completely! It is a web application where anyone — even a non-technical beginner — can upload a CSV/Excel file, click 1 button to clean missing values, visualize charts, scrape data from website links, auto-train AI models, and download a finished PDF report without writing a single line of code!

Chapter 2: Beginner's Guide to Web Technologies Used

Here are the technologies used to build IntelliHub AI and why we chose them:

1. Python (3.11 / 3.13)

The primary backend language. Python is the world standard for Data Science and Artificial Intelligence because of its rich libraries like Pandas, NumPy, and Scikit-Learn.

2. Django 5.2 Framework

A powerful Python web framework. It provides built-in user authentication, security features (CSRF protection, SQL injection defense), database routing, and URL routing out of the box.

3. Bootstrap 5 + Custom CSS

Used for the user interface (UI). Provides responsive grids for mobile, tablet, and laptop screens, styled with a modern Dark Glassmorphism theme (semi-transparent glass cards with glowing cyan highlights).

4. Pandas & NumPy

Pandas loads CSV and Excel files into memory as DataFrames (tables). NumPy performs fast numerical operations and mathematical array calculations.

5. Scikit-Learn (ML Library)

The core Machine Learning library. Performs data preprocessing (Label Encoding), model training (Random Forest, Decision Tree, Logistic Regression, SVM, KNN), and metrics calculation.

6. ReportLab & BeautifulSoup4

ReportLab dynamically builds PDF executive reports. BeautifulSoup4 scans HTML web pages to extract data tables for the Universal Web Scraper.

Chapter 3: How Django Works (MVT Architecture Explained)

If the jury asks "What architecture does your app use?", you must answer: "Django's MVT Architecture (Model - View - Template)".

M - Model

Defines database tables in Python classes (models.py). Django automatically converts Python objects into SQL database tables!

V - View

The core business logic (views.py). It receives HTTP requests from the browser, performs Python processing (cleaning, ML training), and prepares data for the template.

T - Template

The visual HTML webpage (.html files). Displays data passed from the View using template variables like {{ user.username }} and loops {% for item in list %}.

Chapter 5: Detailed Page-by-Page & Functionality Walkthrough

URL Routes: /accounts/login/, /accounts/register/, /accounts/profile/

  • Registration Page: User enters Username, Email, Password, and selects a Role (Data Scientist, Researcher, Student, Company). Handled by UserRegistrationForm in apps/accounts/forms.py.

2Main Dashboard Overview (Dashboard App)

URL Route: /dashboard/ | Template: templates/dashboard/dashboard.html

  • First-Time User Prompt: Controlled by is_first_time = (user_datasets == 0) in apps/dashboard/views.py. When a user has 0 datasets, a large glowing welcome card prompts them: "Welcome to IntelliHub AI! Upload your first dataset to get started."
  • KPI Metric Cards: Displays total user datasets, active ML models trained, total prediction runs, and average accuracy score.
  • Recent Activity Tables: Shows top 5 recently uploaded datasets and trained models with quick actions.

3Dataset Management & Versioning (Datasets App)

URL Route: /datasets/ | Template: templates/datasets/dataset_list.html

  • Uploading: User uploads CSV or Excel file. The file is validated, saved to media storage, and initial version v1 is created.
  • Version Control System: Models defined in apps/datasets/models.py:
    • Dataset: Holds metadata (name, description, owner, creation date).
    • DatasetVersion: Stores the actual file path, version_number, row count, column count, memory usage, duplicate count, missing values count.
  • Immutable History: When data is cleaned or transformed, a new DatasetVersion (e.g., v2) is appended. The raw file v1 is preserved!

4Automated AI Data Cleaner (Cleaner App)

URL Route: /cleaner/ | Template: templates/cleaner/cleaner_home.html

  • Health Status Score: Calculates missing value percentage and duplicate count. Displays status like "Needs Attention" or "Optimal Clean".
  • 1-Click Execute Auto Clean: Triggered via apps/cleaner/services.py function perform_auto_clean():
    1. Removes exact duplicate rows with df.drop_duplicates().
    2. Imputes missing numerical values with column median/mean.
    3. Caps numerical outliers outside 1.5*IQR bounds.
    4. Encodes text categories into numbers using Scikit-Learn LabelEncoder.
  • Download Cleaned Dataset Button: A green button appears after auto clean execution allowing the user to instantly download the cleaned CSV file version!

5Exploratory Data Analysis (EDA App)

URL Route: /eda/ | Template: templates/eda/eda_home.html

  • Calculates overview statistics: Total Rows, Total Columns, Numerical Column Count, Categorical Column Count.

6AutoML & Machine Learning Studio (ML Studio App)

URL Route: /ml-studio/ | Template: templates/ml_studio/ml_home.html

  • Model Benchmarking: Fits multiple models simultaneously using apps/ml_studio/services.py:

    • Support Vector Machines (SVC / SVR)

7Universal Web Scraper (Scraper App)

URL Route: /scraper/ | Template: templates/scraper/scraper.html

Chapter 6: Deep Technical Algorithms & Math Logic

If the jury asks "What mathematical formulas or algorithms did you use?", explain these exact 4 concepts:

1. Outlier Detection using Interquartile Range (IQR)
Formula:
Q1 = 25th Percentile | Q3 = 75th Percentile
IQR = Q3 - Q1
Lower Bound = Q1 - 1.5 * IQR
Upper Bound = Q3 + 1.5 * IQR

Logic: Any data point less than Lower Bound or greater than Upper Bound is an outlier. We cap those values to the boundary numbers so extreme values don't distort ML training.
2. Missing Value Imputation
Logic:
• For Numerical Columns: Replace missing NaN values with column Median (or Mean) using df[col].fillna(df[col].median()).
• For Categorical Columns: Replace missing values with column Mode (most frequent value).
3. Categorical Label Encoding
Logic: Machine Learning models cannot understand string words like "Red", "Blue", "Green". We use Scikit-Learn's LabelEncoder() to convert categories into integers: Red = 0, Blue = 1, Green = 2.
4. ML Evaluation Metrics ($R^2$ Score & Accuracy)
Classification Accuracy: $\text{Accuracy} = \frac{\text{Correct Predictions}}{\text{Total Predictions}}$

Regression $R^2$ Score (Coefficient of Determination): Measures how well the model predicts continuous numerical values relative to the mean. $R^2 = 1.0$ means 100% perfect prediction!

Chapter 7: How Deployment Works (Vercel & SQLite)

How the site runs live at https://intellihub-ai-portal.vercel.app/:

  1. Serverless Architecture: Hosted on Vercel using Python 3.12 serverless runtime via intellihub/wsgi.py.
  2. Database in /tmp: On Vercel, the main file system is read-only. On container startup, our SQLite database file db.sqlite3 is loaded, allowing superfast database queries.
  3. Session Handling: Configured SESSION_ENGINE = 'django.contrib.sessions.backends.signed_cookies'. Session data is encrypted and stored in user browser cookies, ensuring user logins persist smoothly!
  4. Static Assets: Handled using WhiteNoise 6.12 middleware in intellihub/settings.py to serve CSS, JavaScript, and fonts directly from memory with gzip compression.

Term Simple Beginner Definition
DataFrameA 2-dimensional table of data with rows and columns in Pandas (like a spreadsheet in Python).
ImputationThe process of filling in blank / missing values in a dataset with statistical estimates (mean, median, mode).
OutlierAn extreme value in data that differs significantly from other observations (e.g. house price of $1,000,000 when rest are $50,000).
AutoMLAutomated Machine Learning — automatically trying multiple ML algorithms and picking the best one without manual tuning.
CSRF TokenCross-Site Request Forgery security token — a secret code generated by Django to ensure forms are submitted by real users, not hackers.

Chapter 9: 25 Master Jury Questions & Exact Answers

Q1: What is the main aim of IntelliHub AI?
Answer: To provide an all-in-one, zero-code enterprise web platform that combines data ingestion, web scraping, automated cleaning, exploratory analysis, AutoML model training, and executive PDF reporting under a single unified application.
Q2: Which framework and language did you use for the backend?
Answer: We used Python (3.11/3.13) and the Django 5.2 web framework.
Q3: How do you handle missing data in the dataset?
Answer: In apps/cleaner/services.py, we impute numerical missing values using column median/mean, and categorical missing values using the statistical mode (most frequent item).
Q4: How does your dataset versioning feature work?
Answer: Using two Django models: Dataset and DatasetVersion. Every time a dataset is modified or cleaned, a new DatasetVersion record (v1, v2) is saved. The original raw file is never overwritten.
Q5: How does the web scraper work?
Answer: It sends an HTTP GET request to the user's provided URL using requests, parses HTML tables using BeautifulSoup4, converts them into Pandas DataFrames, and lets users save them to Dataset Manager in 1-click.
Q6: What ML models are included in your AutoML engine?
Answer: Random Forest, Support Vector Machines (SVM), Decision Trees, Logistic Regression, Linear Regression, and K-Nearest Neighbors (KNN) from Scikit-Learn.
Q7: How do you evaluate machine learning models?
Answer: For classification, we use Accuracy, Precision, Recall, F1-Score, and Confusion Matrix. For regression, we use R² Score and Mean Squared Error (MSE).
Q8: How do you handle non-numeric categorical text before training ML models?
Answer: We use Scikit-Learn's LabelEncoder to map string text categories into numerical integers (e.g. 0, 1, 2).
Q9: What library is used to generate downloadable PDF reports?
Answer: ReportLab 5.0 in Python.
Q10: Where is your project hosted live?
Answer: Deployed live on Vercel at https://intellihub-ai-portal.vercel.app/.
Q11: How do you secure user authentication and passwords?
Answer: Passwords are hashed using PBKDF2 with SHA-256 algorithm. Form submissions use CSRF protection tokens, and session cookies use HTTPOnly and SameSite=Lax flags.
Q12: How is the UI designed?
Answer: Responsive Bootstrap 5 layout with a custom Dark Glassmorphism design system using semi-transparent frosted glass cards and cyan accents.
Q13: Can a first-time user use the app easily?
Answer: Yes! We implemented an automated onboarding flow. If a user has 0 datasets, a large welcome card guides them to upload their first file or scrape web data before using analytics.
Q14: What happens if a dataset has duplicate rows?
Answer: The AI Data Cleaner detects duplicates and removes them using Pandas df.drop_duplicates().
Q15: How do you detect outliers in numeric data?
Answer: Using the Interquartile Range (IQR) method: [Q1 - 1.5*IQR, Q3 + 1.5*IQR].
Q16: What is the purpose of the AI Analyst Assistant?
Answer: It allows users to ask questions about loaded dataset statistics in plain English without writing database queries.
Q17: How is user role management structured?
Answer: Custom Django User model extending AbstractUser with roles: ADMIN, DATA_SCIENTIST, RESEARCHER, STUDENT, COMPANY.
Q18: What is the difference between Regression and Classification in your AutoML?
Answer: Regression predicts continuous numerical numbers (e.g. house price). Classification predicts discrete categories (e.g. Yes/No, Spam/Not Spam).
Q19: How are static files (CSS, JS) served on Vercel?
Answer: Served using WhiteNoise middleware which compresses and caches static assets efficiently.
Q20: Can users download cleaned data?
Answer: Yes, a green "Download Cleaned Dataset" button appears in the AI Data Cleaner as soon as auto-cleaning is executed.
Q21: How do you prevent layout breakage in the web scraper table view?
Answer: We configured table cell wrapping with CSS word-break: break-word; white-space: normal; so text wraps properly on portrait and mobile displays.
Q22: Why did you use Django instead of Flask?
Answer: Django is an "batteries-included" enterprise framework with built-in ORM, admin portal, user authentication, and security middleware, making it more robust for scalable production apps.
Q23: What database engine is used in production?
Answer: SQLite engine optimized for serverless deployment with sessions managed via signed cookie backend.
Q24: What future enhancements are planned for IntelliHub AI?
Answer: Direct integration with OpenAI/Claude LLM APIs, 1-click SQL database connectors (PostgreSQL/Snowflake), and Apache Kafka real-time data streaming.

Answer: Suraj Vaghela, Nandish Patel, and Himanshu Namsa from LJ University.
